# DigDuel Mod

A 1v1 mining challenge mod for Fabric 1.21.1

## Features

- 4-tier custom minerals
- Level-based pickaxes
- Step-structured mine
- NPC trader
- Victory block

## Requirements

- Fabric Loader 0.14.0 or higher
- Fabric API
- Minecraft 1.21.1

## Installation

1. Download the mod JAR file.
2. Place it in your `mods` folder.
3. Launch Minecraft with Fabric.

## Usage

1. Spawn the mine structure using the appropriate command.
2. Equip the level-based pickaxe.
3. Mine the custom minerals to progress through the tiers.
4. Reach the victory block to win the challenge.

## Configuration

The mod does not have a configuration file. All settings are hardcoded within the mod.
